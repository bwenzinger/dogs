Project knowledge base for the dogs repository.

- Primary purpose: build a clean, modern Vite + React adoption showcase page for a dog.
- Static assets: the dog photos are served from the local `images/` folder in this repository.
- App setup: uses Vite, React, TypeScript, MUI, ESLint, Prettier.
- Contact button: sends email to `test@gmail.com` via mailto.
- Deployment mirrors the MLB The Show home-server flow: systemd service via `scripts/install-systemd-service.sh`, deploy-on-push via `.github/workflows/deploy-home-server.yml`, and fast-forward deploy script at `scripts/deploy-from-git.sh`.
- Server default: live clone at `/home/bwenzinger/dev/dogs`, service name `dogs`, Vite preview host `0.0.0.0`, port `4173`.
- GitHub Actions deploy workflow requires a self-hosted Linux runner with custom label `dogs`; use a dedicated runner directory such as `~/actions-runner-dogs` to avoid overlapping with other local runners.
- AI usage guidance: any AI working on this repo should read this file first and update it with relevant details as changes are made.
